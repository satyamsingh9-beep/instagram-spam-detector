# Instagram Spam Detector

An AI-powered spam detection system that classifies Instagram/social media comments as spam or genuine using Natural Language Processing and Machine Learning.

---

## Features

* Spam vs Genuine comment detection
* NLP text preprocessing
* TF-IDF vectorization
* Logistic Regression classifier
* Real-time user comment testing

---

## Technologies Used

* Python
* Pandas
* Scikit-learn
* NLP
* TF-IDF
* Logistic Regression

---

## Workflow

Dataset → Text Cleaning → Vectorization → Model Training → Prediction

---

## Example

Input:
"free followers link"

Output:
Spam Comment

---

## Accuracy

Achieved approximately 89% accuracy on spam classification dataset.

---

## Dataset

YouTube Spam Collection Dataset
